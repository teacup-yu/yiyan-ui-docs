# YIYAN UI · 组件文档站

意延机电周界入侵探测设计系统(YIYAN Design System, Migration v2)的组件说明文档。

**在线访问**:部署到 GitHub Pages 后,地址为 `https://<账号>.github.io/<仓库名>/`

## 关于本仓库

本仓库**只存放文档站的构建产物**(静态 HTML/CSS/JS),内容由源码仓库构建生成,**请勿直接修改**:

```bash
# 在源码仓库中重新生成并同步
npm run deploy:docs
```

组件库通过 npm 使用:

```bash
npm install yiyan-ui
```
